# Ayıkla! Sosyal Medyanın Dilini

Akdere Anadolu Lisesi · 2026-2027 Dilimizin Zenginlikleri Projesi, Faaliyet 5.3: "Ayıkla Sosyal Medyanın Dilini" Sözlük Çalışması.

Sosyal medyada kullanılan kısaltmaların, yabancı kelimelerin ve yazım yanlışlarının doğrusunu gösteren sözlük:

- 192 kelime, her biri örnek cümleyle
- Sesli "Yanlış! Doğrusu…" gösterisi (ElevenLabs ile seslendirildi)
- 10 soruluk Ayıkla! oyunu
- Mesaj düzeltici

Sitede emin olunamayan kelimeler için TDK Güncel Türkçe Sözlük'e bakılması önerilir.
